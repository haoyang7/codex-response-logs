字段说明与采集状态

时间下方标注日期与来源；「—」表示未记录，「…」表示等待终态。传输列中的 WS 表示 WebSocket，悬停可查看完整名称。模型分行显示本地请求与服务端返回值；档位从左至右为本地请求、首个返回、最终返回。行末可展开模型、档位、完整时间、用量、错误、ID 与轮次；搜索也支持这些字段。按 / 开始搜索，Esc 清除搜索或收起详情。向下翻阅时保留阅读位置，可点「回到最新」返回顶部。右上角的主题图标可选择浅色、深色或跟随系统，默认跟随系统。

常规日志目录可能为空；桌面日志中也可以包含 SSE / WebSocket 响应事件。

表格仅显示最近的响应，超过上限时较早记录移出；原始日志文件由 Codex 写入，不受表格条数限制。请求模型与档位来自本地会话记录，返回值来自 SSE / WebSocket 原文。未关联记录会在会话信息到达后补齐。服务端响应历时不包含完整客户端请求过程，不能当作端到端耗时。

结束进行中的任务并完全退出桌面应用后，在 macOS 终端运行。应用可能显示为 Codex 或 ChatGPT，命令按应用标识定位：

open -b com.openai.codex \
  --env 'RUST_LOG=warn,codex_api=trace,tungstenite::protocol=trace,tungstenite::protocol::frame=off' \
  --env 'CODEX_MAX_LOG_LEVEL=debug'

若系统找不到该应用，请在访达中确认实际位置，将 -b com.openai.codex 替换为 -a "/实际路径/应用名称.app"。

已有完整响应日志时，无需重复启动 Codex。历史记录中未落盘的字段无法补采；返回档位仅表示服务端回传值。
